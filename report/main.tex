\section*{Conventions}
Slots are 0-based, $\sigma(t_i) \in \{0,\dots,K-1\}$, exactly as the provided
generator produces windows. The base penalty therefore charges $\sigma(t_i)+1$,
which equals the spec's 1-based slot index: slot 0 still costs $w_i$, and the
optimum is never 0. The toy instance of \S3.3 is stored with its windows
shifted by $-1$. We write $W = \sum_i w_i$.
